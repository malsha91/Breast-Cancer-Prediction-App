Breast Cancer Prediction (Logistic Regression)

This project uses the Breast Cancer Wisconsin (Diagnostic) dataset from Kaggle. The dataset contains numerical features extracted from digitized images of fine needle aspirates (FNA) of breast tissue, describing the shape and texture of cell nuclei. These features are used to classify tumors as Benign or Malignant.

A Logistic Regression model was trained on the dataset for binary classification.

The project includes a Streamlit app that allows users to upload data or enter values manually to generate predictions.
